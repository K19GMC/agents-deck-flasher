Write agents deck firmware to a supported board over USB, straight from your browser. Nothing to install.

Chrome or Edge on desktop · Web Serial
This browser can't flash boards. Flashing uses Web Serial, which Chrome and Edge have on desktop. Open this page in one of those over https, on the computer the board is plugged into.

How to flash

  1. Plug the board into this computer with a USB-C data cable (not a charge-only one).
  2. Click Install on your board.
  3. In the browser's port picker, choose the board's USB port (usually USB JTAG/serial or USB Single Serial).
  4. Leave it connected until it finishes — about a minute. The board restarts into agents deck when it's done.

Nothing happens when you click Install? Another program may hold the port — close any serial monitor, and make sure agents deck isn't using the board. If the board doesn't answer, hold BOOT, tap RST, release BOOT, then try again.

Firmware built from brushknight/agents-deck with an M5Stack StickS3 device port. Images are written at 0x0 (bootloader + partition table + app). Over Web Serial only.
